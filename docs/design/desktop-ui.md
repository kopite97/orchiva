# 데스크톱 화면 와이어프레임

작성일: 2026-11-16 · 당시 상태: 검토용 제안, 앱 구현 미착수

2026-11-26 UI-A 범위 수용 완료: 프로젝트 중심 탐색과 화면 분리, 본문/요약 카드, 폭별 배치, 결과·검사·판정 이력 표현을 실제 WinUI에서 확인했다. [화면별 전후 근거](../evidence/desktop-ui-alignment/20261126-ui-001/README.md). 기능 추가는 없으며 12 상담과 미지원 분야는 비활성이다. 사용자는 화면배율 100%를 사용 기준으로 정했고 배율 변경 검증은 지금 수행하지 않도록 했다. 이번 증거는 실제 125% 환경의 관측이며 다른 배율의 통과를 의미하지 않는다. 아래는 최초 제안과 중간 실행 이력이다.

2026-11-17 현재 상태: D1~D3 구현·비GUI 검증은 진행 완료했으며 아래는 최초 시안 작성 당시 설명이다. 승인된 [UI-A 보정 PLAN](../plans/desktop-ui-alignment.md)에 따라 페이지 분리·프로젝트 탐색·카드/반응형 UI 코드를 적용했다. 기능 기준은 [D2·D3 완료 기록](../decisions/desktop-d2-d3-completion.md)을 우선하고, 시안에만 있는 기능은 제외한다. 기존 이미지 원본은 유지한다. 빌드 및 모의/격리 회귀는 통과했지만 변경 후 컴퓨터 유스가 물리 Escape로 중지되어 실제 시각 수용은 대기한다. [UI-A 중간 결과](../decisions/desktop-ui-alignment.md)를 참조한다.

[전환 설계](desktop-transition.md)와 [PLAN](../plans/desktop-transition.md)을 바탕으로 페이지별 와이어프레임을 작성했다. 사용자 요청에 따른 설계 산출물이며 D1 구현을 시작하거나 완료한 것으로 취급하지 않는다. 화면 구조·버튼 배치·문구·테마의 최종 승인은 아직 없다.

## 확정과 제안

- 확정: WinUI 3 + .NET 10, 프로젝트별 실제 파일·docs 관리, 정형 입력 → AI의 템플릿 내 PLAN 내용 작성 → 확인 → 실행, 결과 검토와 B안 선택 반영, 앱 종료/트레이 최소화 설정.
- 제안: 좌측 프로젝트 탐색, 중앙 작업 화면, 필요한 화면만 우측 요약 영역, 하단 주요 행동. 단색 중심 와이어프레임이며 브랜드 색·글꼴 크기·여백·아이콘·세부 구성은 검토 대상이다.
- 미정: 닫기 설정 기본값과 앱 종료 시 진행 작업 처리, 일반 폴더 제작 지원. 질문/상담의 PLAN 자동 완성·제작 전환 기능은 이번 범위에서 제외한다.
- 시안은 합성 프로젝트와 예시 데이터만 사용한다. 파일 탐색·초기화·저장·모델 호출·소스 반영은 실제 실행하지 않는다. 분야 선택에 따라 요청의 규격 입력 예시는 바뀌며, PLAN·실행·결과 상세는 코딩 사례로 제시한다.

## 공통 UX와 후속 검토

- 주요 경로는 프로젝트 추가 → 소스 지정 → 초기화 → 분야 → 요청 → PLAN → 실행 → 결과 → 선택 반영이다. 좌측 탐색은 PLAN 이력·지침·질문·설정으로 바로 이동한다.
- 파일명·사용자 작성 검사 코드 입력란을 두지 않는다. 모델과 수준은 실제 지원 옵션을 조회해야 하므로 시안에서는 특정 제품명이나 지원 수준을 확정하지 않는다.
- 실행 단계에 근거 없는 완료율을 표시하지 않는다. 관측 불가와 실행 실패를 구분하고, 검증 완료와 사람의 품질 확인·소스 반영을 별도 행동으로 둔다.
- 좁은 미리보기에서는 영역을 세로로 배치한다. 실제 Windows 앱의 최소 창 크기·DPI·키보드·접근성 검증은 D1에서 별도로 수행한다. 브라우저 시안 검사는 WinUI 검증을 대체하지 않는다.
- 다음 디자인 검토에서는 좌측 탐색 구조, 주요 행동 위치, 입력의 밀도, PLAN/결과의 문서 폭을 먼저 정한다. 이후 색상·타이포그래피·간격·테마를 공통 리소스로 정의한다.
- 미디어 결과의 실제 이미지·음원·효과 미리보기, 파일 선택/충돌 해소 대화상자, 트레이 메뉴의 상세 배치는 해당 단계에서 추가 설계한다. 이 와이어프레임으로 미디어 도구나 실행 기능이 구현됐다고 표시하지 않는다.

## 저장된 화면 이미지

사용자가 확인한 와이어프레임을 페이지별 PNG 14개로 보관했다. [현재 PLAN의 이미지 목록](../plans/desktop-transition.md#와이어프레임-참고-이미지)에서 각 화면을 열 수 있다. 원본은 `docs/evidence/desktop-transition/20261116-wireframe-capture-001/`에 있으며 모두 밝은 테마·코딩 예시 기본 상태다. 대화 밖에서도 참고할 수 있는 정적 자료이며 최종 시각 디자인이나 앱 구현 완료를 뜻하지 않는다.

## 검증 기록

검토용 대화 시안은 `orchiva-wireframes.html`이며 저장소 런타임 파일에 포함하지 않는다. 정적 문서와 시안의 검증 범위·결과는 [와이어프레임 검증 근거](../evidence/desktop-transition/20261116-wireframe-001/summary.json)에 기록한다. 표시한 예시는 현재 PC의 실제 실행 상태가 아니다.
