# Orchiva 구현 계획 목록

제품 범위는 [MVP 설계](../mvp-design.md), 작업 절차는 [공통 흐름](../agents/workflow.md), 계획 작성·상태 규칙은 [계획 규칙](AGENTS.md)을 따른다.

## 등록된 계획

| 순서 | 계획 | 상태 | 실행 범위 |
| --- | --- | --- | --- |
| 1 | [M0 실행 기반 확인](m0-runtime-foundation.md) | `proposed` | 브라우저 없는 연결, 생성·전송 대조, 기준 커밋 고정, 종료 처리 |

현재 활성 구현 계획은 없다. 2026년 11월 12일 사용자 요청은 하네스 설정과 M0 상세 계획 작성까지다. 소스 원격 저장소 등록과 기본 소스 폴더 지정은 반영했으며 M0 런타임 구현·실험은 시작하지 않았다.

## 후속 단계

다음은 설계상의 순서다. 상세 계획을 작성할 때 위 목록에 등록하며, 이 표만으로 구현 상태나 승인을 나타내지 않는다.

| 단계 | 범위 | 선행 입력 |
| --- | --- | --- |
| M1 | 저장·상태 모델, v2 마이그레이션, 명령·결과·판정 이력, 실행 슬롯 | M0의 연결·멱등성·복원 제약 |
| M2 | 요청 초안, 완료 조건·검사 편집, 계획 확인과 실행 | M1 계약과 상태 모델 |
| M3 | 목록·진행 화면, 백그라운드 대조와 재시작 복원 | M0 연결 수명, M1 상태, M2 실행 |
| M4 | 결과·조건별 판정·재검증·검사 변경 표시 | M1 결과 이력과 M3 관측 |
| M5 | 초기 재시도·동일 세션 복구·명령 중복 제거 | M0 전달 정책, M1·M4 이력 |
| M6 | 통합 수용·장애 시험·측정·사용 안내 | M1~M5와 설계의 A01~A16 |

## 하네스 설정 기록

하네스는 Plugin 루트 지침 지도, 공통 작업·소스·검증 규칙, 문서·계획 규칙과 템플릿으로 구성한다. sandbox에는 역할과 Plugin 지침 연결을 둔다.

2026-11-12 정적 검증: 관련 문서 14개, 로컬 링크 57건의 대상 존재, 인코딩·코드 블록, M0 템플릿 절·상태 일치, 기존 npm 검증 명령 존재를 확인하여 통과했다. M0 검증 시나리오는 V01~V11로 정의했으며 아직 실행하지 않았다. 문서·Git 연결 설정만 변경한 이번 작업에서는 타입 검사·런타임 테스트·daemon 재시작을 수행하지 않았다.
