# M2 초안·계획 확인·고정 커밋 실행

- 상태: `completed`
- 작성일: 2026-11-12 · Asia/Seoul
- 관련 설계: [MVP 설계](../design/mvp-design.md)의 입력·계획 규칙, 요청 작성·계획 확인, M2
- 선행 조건: [M1 결과](../decisions/m1-storage-state.md), 기준 커밋 `bd08ace`
- 실행 근거: 사용자가 M2 상세 계획과 그 계획의 구현·검증을 지시했다. 등록 후 같은 작업에서 활성화한다.

## 목표

입력만으로 실행되던 PoC 흐름을 초안 저장→계획 확인→명시적 실행으로 바꾼다. 불완전한 초안을 다시 열 수 있고, 완료 조건·검사 정의와 두 PLAN을 확인한 현재 버전만 실행할 수 있어야 한다. 기준 브랜치가 움직이면 재확인을 요구하며, 확인 이후 생성 시점에 ref가 움직여도 저장한 SHA로 생성한다.

## 현재 근거와 확인할 사항

M1은 원자적 저장·revision·명령 이력·슬롯을 제공하지만 입력은 모두 필수이며 start가 즉시 생성한다. M0의 `createPinnedWorkspace`는 SHA 전달과 HEAD 검증을 실증했지만 현재 요청 시작은 baseRef를 사용한다. UI는 단일 입력폼과 결과 카드다. SDK의 동기 등록·ready gate를 유지한다. 기존 4건의 결과·판정·ID는 그대로 보존한다.

## 범위

포함: draft/ready 상태, 불완전 입력 저장·재열기, 구조화된 조건(최대20)과 검사(최대8), 조건의 검사/수동 방법 연결, 읽기 전용 사전 점검, 두 PLAN 버전·입력 해시·기준 SHA, 확인 시작 RPC, 현재 프로젝트/커밋 대조, 고정 SHA 생성, 작성·계획 화면과 저장되지 않은 입력 이탈 확인.

기존 start 입력은 이미 실행한 기록의 동일 입력 참조만 허용한다. 새 요청의 계획 우회는 서버에서 거부한다. 신규 계획 명령에 키와 expectedRevision을 요구한다. 시작 의도는 외부 효과 전에 저장하며 HTTP/RPC 연결 취소를 효과 취소로 가정하지 않는다. daemon 중단 후 자동 실행 재개는 M3/M5다.

제외: 전체 목록 페이지네이션·상세 탭 개편(M3), 조건별 최종 판정(M4), 새 초기 재시도와 unknown 해결 UI(M5). 실제 시험은 sandbox 새 요청·Worktree·Codex 세션 1건과 읽기 전용 GUI를 기본으로 한다. ref 이동 시험은 전용 임시 ref만 사용하며 main·원격은 변경하지 않는다. 기존 PoC는 사전 바이트 백업과 회귀 비교에만 사용한다.

초안 수정은 과거 PLAN을 삭제하지 않고 상태를 draft로 바꾼다. 새 준비 시 다음 PLAN revision을 발급한다. 현재 준비된 계획만 실행하며, 저장소의 요청 revision과 계획 revision을 구분한다. 실행 수락 후 feature·criteria·checks·계획·프로젝트 스냅샷을 고정한다. 수동 검사만 있는 요청도 허용하되 자동 검증 없음 표시를 유지한다.

## 실패 처리와 복원

원본을 실행 ID별로 백업한다. 신규 세션만 시험하고 이전 결과·검사 기준을 수정하지 않는다. 입력·준비 실패는 사용자 입력을 유지한다. 전달 결과가 미확정이면 같은 저장 의도를 보존하고 새 키로 효과를 만들지 않는다. GUI/daemon 재로드는 활성 작업이 없는 것을 확인한 뒤 수행한다. 임시 ref는 소유한 정확한 값일 때만 제거한다. 시험 리소스는 증거로 보존하며 원격 push·merge는 하지 않는다.

## 결정과 후속 작업

상세 진행/이력 화면은 M3·M4에 넘기되 M2 작성·계획 화면에서 기존 결과 카드로 이동할 수 있게 한다. 기존 완료 기록에 계획 확인을 소급 요구하지 않는다. 계획 내용은 입력 기반 템플릿이며 별도 모델 호출로 만들지 않는다.

SDK 이름 제약으로 RPC를 소문자 하이픈 형태로 등록했다. M2는 실제 모델 실행1회와 임시 ref 이동을 검증했으며 확인 직후 ref 이동·응답 미확정은 모의 회귀로 구분한다. 실행 의도 저장 후 생성이 끝나야 RPC가 응답하는 현재 구조, 자동 재시작 복원 부재, 기존 단일 완료 판정과 내부 화면 이동에 한정된 미저장 보호를 [결과와 후속 계약](../decisions/m2-draft-plan-start.md)에 기록했다.
