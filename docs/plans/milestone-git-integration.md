## 목표

2026-11-26 후속 요청에서 사용자가 실제 독립 리뷰·필수 검사·PR 병합·Issue 종료 시험을 승인했다. 현재 저장소 협업자는 PR 작성자 1명이다.

같은 PLAN을 로컬 Git과 GitHub Issue에서 추적하고 승인된 파일만 Feature 브랜치에서 통합한다. GitHub가 없는 프로젝트에서도 로컬 완료 기준을 사용할 수 있다.

## 현재 근거와 확인할 사항

[고정 SHA Worktree](../../server/adapters/paseo/pinned-workspace.ts)와 [산출물 비교](../../server/application/desktop/artifacts.ts)가 있다. 현재 실행은 미커밋 소스까지 snapshot에 포함하고 제작 프롬프트는 commit/push/merge를 금지한다. 신규 게시 경계에서 사용자 변경 혼입을 검사해야 한다.

## 범위

로컬 선택 적용/관리 브랜치 통합을 실행별로 고정한다. 구현 시 실제 원격 쓰기는 지정된 시험 저장소의 Issue·Feature PR·시험 통합 브랜치에 한한다. 실제 배포, 사용자 checkout 병합, 운영 저장소 쓰기는 제외한다. 응답 유실은 모의 운반 계층과 시험 소유 요청에서 재현한다.

## 실패 처리와 복원

원격 timeout은 닫힌 Issue를 포함해 식별자·head·병합 여부를 조회한다. 단일 후보를 확정할 수 없으면 수동 대조를 기다린다. 충돌/실패 Worktree는 보존하고 소유·clean 상태 및 증거 회수를 확인한 항목만 정리한다.
