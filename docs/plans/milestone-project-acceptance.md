# MA6 분야별 프로필 재사용과 프로젝트 수용

- 상태: `completed`
- 작성일: 2026-11-26 · Asia/Seoul
- 관련 설계: [로드맵 파이프라인 검토](../design/roadmap-pipeline-review.md) · [실행 순서](README.md)
- 선행 조건: [MA2](milestone-local-run.md)의 역할·지침·run 기록과 [MA5](milestone-unity-validation.md)의 실제 게이트. 활성화할 분야의 실제 제작 도구·검증기 유무를 D5 현황과 대조한다.
- 실행 근거: 사용자가 두 게임의 MA6 구현과 실제 로컬 PoC를 요청했다. 2026-11-26 두 Windows 빌드에 대한 사용자 승인을 받고 후속 Phase의 첫 PLAN까지 확인했다. [두 게임 수용 기록](../decisions/milestone-project-acceptance.md)

## 목표

두 게임에서 같은 파이프라인을 사용하고 서로 다른 분야 지침·검증·승인이 올바르게 적용되는지 확인한다. 개발자는 구간의 비용·근거·잔여 결정을 보고 다음 Phase 진행 여부를 정한다.

## 현재 근거와 확인할 사항

[프로젝트 초기화 템플릿](../../server/application/desktop/project-templates.ts)과 [제작 입력 계약](../../shared/contracts/desktop-production.ts)은 기획·코딩에 적용된다. [데스크톱 전환](desktop-transition.md)의 D5는 분야별 제작 도구, D6는 배포·새 PC 수용을 소유한다. 이 계획은 사용 가능한 도구의 파이프라인 연결과 운영 수용을 다룬다.

## 범위

프로젝트별 설정 배포·버전 관리, 결과 인계, 반복 운영 및 화면 수용을 포함한다. 격리된 두 게임에서 실제 제작·중단·재등록을 시험한다. 설치 패키징, 외부 Orchestrator 도입, D5 생성기 자체 개발, 실제 서비스 배포는 별도 범위다.

## 실패 처리와 복원

프로필 변경은 후속 revision으로 적용하고 이미 실행한 요청은 기존 정책에 연결한다. 지원 도구가 없는 분야는 미실행으로 남기고 D5 제공 여부를 기록한다. 대체 도구나 텍스트 파일만으로 실제 분야 수용을 통과 처리하지 않는다.
