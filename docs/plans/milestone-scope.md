- 작성일: 2026-11-26 · Asia/Seoul
- 관련 설계: [로드맵 파이프라인 검토](../design/roadmap-pipeline-review.md) · [실행 순서](README.md)
- 선행 조건: D3의 프로젝트·지침 조회와 UI-A 작업실을 기준으로 한다. [UI-A 완료 기록](../decisions/desktop-ui-alignment.md)의 합성 GUI 근거와 실제 실행 미확인 항목을 구분한다.
- 실행 근거: 사용자가 검토안에 기반한 구현 PLAN 작성을 요청했다. 이후 2026-11-26에 MA1 구현과 로컬 검증을 승인했다.

## 목표

개발자가 프로젝트의 Phase와 시작·종료 Milestone을 선택하면 포함된 Feature, 관련 지침, 선행 작업과 차단 사유를 확인하고 같은 입력으로 같은 실행 명세를 재현할 수 있다.

## 현재 근거와 확인할 사항

[프로젝트 계약](../../shared/contracts/desktop-project.ts)과 [Projects](../../server/application/desktop/projects.ts)는 지침 원본·scope·해시를 다룬다. [captureInput](../../server/application/desktop/snapshots.ts)은 제작 입력 사본을 보관한다. 로드맵 항목 ID와 구간 계약은 새로 필요하다.

## 범위

대상 게임의 로드맵 읽기·편집·미리보기, 지침 선택, 범위 승인 자료까지 포함한다. 프로젝트 초기화 시 기존 게임 문서를 덮어쓰지 않는다. 모델·Worktree·세션 생성, daemon 재시작, 외부 게시 및 장애 주입은 이 단계 시험에서 제외한다.
